# Contributors

PS Store Enhancer is built and maintained by **Idan** ([@DrummingBird1](https://github.com/DrummingBird1)).

Everyone who contributes code, translations, trophy data, bug reports with useful diagnostics or
store-listing help is credited here — by name or handle, as they prefer. To be added (or to change how
you are listed), mention it in your pull request or open an issue.

## Code and docs

- Idan — maintainer

## Translations

The 16 interface languages (English, עברית, العربية, Español, Français, Deutsch, Italiano,
Português (BR), Nederlands, Polski, Türkçe, Русский, 日本語, 한국어, 简体中文, 繁體中文) were drafted with
AI assistance and are open to native-speaker review. If a phrase reads awkwardly in your language, a
pull request against `extension/_locales/<code>/messages.json` is very welcome — you will be listed
here for it.

## Trophy / completionist data

`extension/data/trophies.json` is community-maintained; contributors of corrections and additions
are listed here.
