📝 Changelog

PS Store Enhancer (formerly GameDeals+, then PS Store Insight) — what's changed in each version

What's new v2.6.1

2026

New look

  • New icon — cleaner mark, still recognizable at 16px in the toolbar.
  • Updated screenshots and promotional images for the Chrome Web Store listing, including Hebrew-localized versions, all built from the extension's real UI and colors rather than generic mockups.
  • Expanded website — the landing page now shows real screenshots of every major feature (product page cards, live search, the stats dashboard, the popup) instead of icon-only feature tiles.

No functional changes to the extension itself in this release.

v2.6.0

2026

Renamed, again — hopefully for the last time

  • PS Store Insight is now PS Store Enhancer — same extension, same developer. This name is shorter and says exactly what it does: it enhances the PlayStation Store page you're already on. Nothing about your settings, PSN connection, wishlist, or owned-games list changes. Backups exported under either older name still import correctly.

v2.5.0

2026

Renamed

  • GameDeals+ is now PS Store Insight — same extension, same developer, same free/open-source project. The new name better reflects what it actually does: price history, cross-platform comparison, review scores and trophy insight layered onto the PlayStation Store. Nothing about your settings, PSN connection, wishlist, or owned-games list changes.

New

  • 🔎 Live search suggestions — as you type in the PS Store search box, PS Store Insight shows an enriched dropdown with box art and the cheapest PC price for matching titles. Selecting one jumps straight to PS Store's own search results for that game. No new permissions required.
  • 🎉 "What's new" surfaces automatically — after any update, a quick highlight card appears in the popup and a dismissible banner appears on the store page, so you never miss what changed. The full changelog is always one click away.
  • 📊 Library & Wishlist stats — a new dashboard on the settings page shows games owned, wishlist size, total wishlist value, and how many deals are ready to buy right now — all computed from data you already have, no extra API calls.
  • 🔔 Toolbar badge — the extension icon now shows a live count of wishlist deals at or below your target price (green), or a dot when there's an unread "what's new" (red).
  • 🎁 Edition transparency — cross-platform price rows are now tagged when a listing is for a different bundle/edition (Deluxe, Ultimate, GOTY, etc.) than the PS Store page you're viewing, so you're never comparing a base game's price to a special edition's without knowing it.
  • ♿ Accessibility — every settings toggle now has a proper screen-reader label, and the new search-suggestions dropdown uses listbox/option roles with keyboard selection state.

Not included (and why)

A few ideas from the community/roadmap list were deliberately left out of this release: importing your PSN wishlist automatically and per-trophy rarity percentages both need real testing against Sony's private API, which isn't something that can be verified without a live PSN account in the loop — shipping either blind risks the same kind of reviewer-facing breakage this project has hit before. A Firefox port is similarly parked until it can be tested in a real Firefox profile rather than assumed to work. Edge already works today since it's Chromium-based — no extra code needed, just a separate store listing.

v2.4.0

2026

New

  • Wishlist notifications are now clickable — clicking a price-drop alert opens that game's PlayStation Store page.
  • "Check prices now" button — manually refresh all wishlist prices from the options page instead of waiting for the daily check.
  • Support the project — added a Patreon link in the popup, options, welcome page, and landing page. GameDeals+ stays free and open-source.

v2.3.2

2026 · Security & compliance

Fixes

  • MV3 CSP fix — moved the welcome page and changelog page scripts out of inline <script> blocks (which Manifest V3 blocks) into external welcome.js / changelog.js. The welcome "Open Settings" button and changelog theme now work.
  • Attribute-safe escaping — esc() / escapeHtml() now escape quotes too, hardening against markup-breakout from unusual game titles.
  • Privacy policy refreshed — now lists notifications, contextMenus, the Frankfurter endpoint, and the daily wishlist price checks; removed the stale activeTab entry.

v2.3.1

2026

UX honesty & clarifications

  • Wishlist disclaimer — the Wishlist UI now clearly states alerts use cross-platform PC prices from CheapShark (Steam/Epic/GOG, USD). PSN-only prices aren't tracked.
  • HowLongToBeat link — trophy card now includes a "Story / completion times on HowLongToBeat →" link for accurate playtime data.
  • "What's New" popup on minor/major updates — `chrome.runtime.onInstalled` opens the changelog automatically when 2.x → 2.y bumps land.
  • Keyboard shortcut — Alt+Shift+G opens the popup (configurable in chrome://extensions/shortcuts).
  • Import loading state — the Import button spinner runs while JSON is parsed.

Developer experience

  • Pure helpers (slugify, fuzzyMatch, computeBasePrice, classifyTitle) extracted to extension/match.js for unit testing.
  • 21 Jest tests covering the matching/pricing/classification logic.
  • ESLint + Prettier configs added; CI workflow runs lint + tests + locale validation on every PR.
  • GitHub Actions release workflow — push a v* tag, get a Release with both zips attached automatically.
  • GitHub Pages live at drummingbird1.github.io/ps-store-insight/ — landing page + privacy policy.
  • Hebrew README, CONTRIBUTING guide, issue templates.

v2.3.0

2026

New features

  • ⭐ Wishlist with price alerts — track games on PS Store, get a desktop notification when their cross-platform cheapest price drops below your target.
  • 💱 Display currency — convert cross-platform prices to your local currency (EUR, GBP, ILS, JPY and 14 more), powered by Frankfurter daily rates.
  • 🎨 Light theme — choose Auto / Dark / Light from settings. Applies to popup, options, injected cards, and changelog.
  • 🌍 Auto-detect region — your PS Store region is now picked up from the URL on first visit.
  • 🖱️ Right-click search — highlight any text on PS Store, right-click "Find on GameDeals+ price compare" to look it up on CheapShark.
  • 📤 Backup & Restore — export your manually-marked owned games and wishlist to JSON, restore from any previous backup.

Improvements

  • Trophy database expanded with 50+ popular PS5 titles (Spider-Man 2, Stellar Blade, Black Myth, Persona, FC 24/25/26, Helldivers 2, Tekken 8 and many more).
  • Cross-platform card now shows currency tag and converts prices using daily exchange rates.
  • Search-grid filtering debounced from 200ms to 500ms with requestIdleCallback — lower CPU on infinite scroll.
  • Friendlier error messages when CheapShark/OpenCritic are temporarily down.
  • Theme-aware injected cards on PS Store match your selected theme.
