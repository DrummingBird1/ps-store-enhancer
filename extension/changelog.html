PS Store Enhancer (formerly GameDeals+, then PS Store Insight) — what's changed in each version

What's new v3.0.0

2026 · "Checked against the real store"

This release was built by opening real PlayStation Store pages and testing the extension's code against them. That found four bugs in v2.7.1 that the old test pages could not show; they are fixed here.

Fixed

  • A wrong PlayStation price could be recorded. On pages with an edition list the extension could pick another edition's price, and a price printed right before more text could be read as 1,000 times too high. It now reads the page's own price from the buy box (JSON-LD as a backup), skips PlayStation Plus trial offers and refuses implausible numbers.
  • The cards sat below the editions list instead of below the buy button on those pages.
  • "Hide add-ons" and "Hide DLC" missed almost everything on the live search page. They now use the store's own label on each tile (Add-on, Add-On Pack, Level, Episode…) and the clean title; a full game sold as a "Game Bundle" is no longer treated as DLC.
  • "Hide games I already own" hid the wrong games: owning "God of War" hid its sequels and kept the game itself. It now compares exact titles (a Deluxe Edition counts as the same game).
  • Hidden search results left blank gaps in the grid; the whole grid cell is hidden now.
  • Connecting PSN failed in Chrome, every time. Chrome only gives the sign-in redirect to a listener that exists when the background worker starts, and Sony's token endpoint answers 403 to a request that carries the extension's Origin header. The listener is now attached at start-up, and a rule removes that header from the one request to Sony's token URL. This adds the permission declarativeNetRequestWithHostAccess (no warning in Chrome; used for nothing else).

New

  • A new look, "Midnight Glass". The cards on store pages, the toolbar popup, the settings page, the welcome page and this changelog share one design: glass surfaces, a bigger headline number for the lowest price, one icon set instead of emoji, and the same colours in dark, light and high contrast (including right-to-left languages). The settings page gets a side navigation. Nothing was removed.
  • Cards stay on the page. The store re-renders its page a few seconds after it loads (for example once it knows you are signed in) and that removed the cards. They are now put back.
  • Support links that led nowhere were removed. The Buy Me a Coffee and Patreon pages returned "not found", so the popup, settings, welcome page, website and readmes now show only Ko-fi.
  • PlayStation price history in the Price Insight card: the lowest PlayStation price you have seen, today's price, the sale (was, % off, when it ends), the PlayStation Plus price when shown, the store's own 30-day low, a trend and the gap to the cheapest PC price. Built only from prices your browser recorded; it says "not enough history yet" until there are two different days. Keeps the latest 400 days with a recorded price (it was 120) and is included in the JSON backup.
  • Prices are recorded from more places: search results update the history of games you already looked at or wishlisted, and once a day the saved page of each wishlisted game is read in the background (at most 20 pages a day, no cookies, store.playstation.com only). Turning off Price insight in Settings stops the search-result recording and the daily read.
  • Check this page (toolbar popup): runs every lookup the extension depends on in the current store tab and shows which work, which work through a fallback and which are not found. If a store redesign breaks one lookup, only that card is switched off on that page and the Diagnostics log says why.
  • Network log (Settings): every request the extension makes — host, path, status and time, never the query, headers or data — kept on your device. The extension can only reach its five documented hosts.

Please note: the PSN sign-in was checked on one real account (connect, library sync of 2,034 games, token refresh, Hide games I already own), and the injected cards were checked by tests against the real page structure and by eye in Chrome with the extension loaded.

What's new v2.7.1

2026 · "PSN connection fix"

v2.7.1 is the first published build of the 2.7 series: it also contains everything from v2.7.0, listed below, which was never released on its own.

Fixed

  • Connecting to PSN could never succeed. The extension identified itself to Sony with the wrong app identity and sent its token requests without the client authentication Sony requires, so every attempt ended in "Could not connect to PSN" — even with a valid NPSSO. Sign-in and token refresh now follow the same documented flow as the open-source psn-api project, and the automated tests use a fake Sony that rejects anything else.
  • The library list asks Sony only for documented categories. It lists games your account has played; add-ons are not part of it, so the DLC counter stays at 0.

Better when something still goes wrong

  • Connection errors now name the failing step in brackets, e.g. [authorize/login-redirect] (the NPSSO is expired or wrong) or [token/401-invalid_client], and the Diagnostics log records Sony's short error name. The bug-report form has a Diagnostics field.
  • When Chrome hides Sony's sign-in redirect, the optional webRequest permission is requested in the same click as Connect (one step instead of two), and the redirect is read from both the response headers and the redirect event.

Please note: this release was checked against the reference implementation and a strict fake of Sony's servers, not yet against a live Sony account. If connecting still fails, copy Settings → Diagnostics into a bug report.

What's new v2.7.0

2026 · "Accuracy & trust"

Fixed — data you can trust

  • Cross-platform prices now show the exact game. The table could list a DLC, a map or a spin-off instead (Elden Ring showed the $15 Nightreign add-on; Cyberpunk 2077 showed a $4.99 map). The extension now resolves the exact CheapShark game first and reads that game's own deals.
  • Review scores work again. OpenCritic's API now requires a key and had stopped returning anything; the badge silently fell back to a short built-in list that could even show the wrong game's score. Scores now come from CheapShark — Metacritic (PC) and the Steam user rating — with no API key, and the OpenCritic permission is gone.
  • No more made-up price history. The 12-month chart was synthesized from a single price. Price Insight now shows only real facts: the lowest PC price ever (with its date), today's cheapest, a "near the all-time low" flag and the trend of prices your own browser recorded.
  • "Owned" detection ignores curly vs straight apostrophes, ™/®, punctuation and edition suffixes, so hide-owned and the owned button work across typography differences.
  • Trophy matching no longer mixes a game up with its sequel or spin-off.
  • Wishlist price checks can no longer overwrite changes you make while they run, and go easier on CheapShark.

Safer PSN

  • Your real Sony cookie is never overwritten any more — it is restored after every connection attempt.
  • One automatic refresh-and-retry when Sony answers 401, and an optional webRequest permission fallback if Chrome hides Sony's sign-in redirect (asked for only when needed).
  • New local Diagnostics log in Settings: the last API and PSN events, kept on your device, tokens and passwords never recorded.
  • Erase all my data in Settings and in the popup.

New

  • Wishlist: "% off" targets, notes, sorting and filtering, a weekly-digest option, a read-only share link (names and last PC prices only — nothing is uploaded) and the PS Store price you saw on each game's page.
  • Product page: collapsible, reorderable and hideable cards, a completionist effort score, price per hour, "similar difficulty" picks from your library, a share-this-deal image, hints about usual sale dates, a first-run tour and a one-time review prompt.
  • Search: ✓ / ★ markers for games you own or wishlisted, junk (soundtracks, maps) filtered out, and "/" to focus the search box.
  • Settings: high-contrast theme, experimental trophy rarity, country and currency names in your language, display currency auto-set from your store region.
  • 6 new languages — Italiano, Polski, Türkçe, Nederlands, 简体中文, 繁體中文 (16 in total).
  • Accessibility: reduced-motion respected, screen-reader announcements when cards load, visible keyboard focus everywhere.

Not included (and why)

Importing your PSN wishlist and the PS Plus catalog badge need Sony data that has no public, verifiable source. "Similar games" needs a genre data source. Bundle detection needs a bundle feed. A Firefox build exists in the repository but is untested and not published. These stay on the roadmap rather than shipping unverified.

v2.5.0

2026

Renamed

  • GameDeals+ is now PS Store Insight — same extension, same developer, same free/open-source project. The new name better reflects what it actually does: price history, cross-platform comparison, review scores and trophy insight layered onto the PlayStation Store. Nothing about your settings, PSN connection, wishlist, or owned-games list changes.

New

  • 🔎 Live search suggestions — as you type in the PS Store search box, PS Store Insight shows an enriched dropdown with box art and the cheapest PC price for matching titles. Selecting one jumps straight to PS Store's own search results for that game. No new permissions required.
  • 🎉 "What's new" surfaces automatically — after any update, a quick highlight card appears in the popup and a dismissible banner appears on the store page, so you never miss what changed. The full changelog is always one click away.
  • 📊 Library & Wishlist stats — a new dashboard on the settings page shows games owned, wishlist size, total wishlist value, and how many deals are ready to buy right now — all computed from data you already have, no extra API calls.
  • 🔔 Toolbar badge — the extension icon now shows a live count of wishlist deals at or below your target price (green), or a dot when there's an unread "what's new" (red).
  • 🎁 Edition transparency — cross-platform price rows are now tagged when a listing is for a different bundle/edition (Deluxe, Ultimate, GOTY, etc.) than the PS Store page you're viewing, so you're never comparing a base game's price to a special edition's without knowing it.
  • ♿ Accessibility — every settings toggle now has a proper screen-reader label, and the new search-suggestions dropdown uses listbox/option roles with keyboard selection state.

Not included (and why)

A few ideas from the community/roadmap list were deliberately left out of this release: importing your PSN wishlist automatically and per-trophy rarity percentages both need real testing against Sony's private API, which isn't something that can be verified without a live PSN account in the loop — shipping either blind risks the same kind of reviewer-facing breakage this project has hit before. A Firefox port is similarly parked until it can be tested in a real Firefox profile rather than assumed to work. Edge already works today since it's Chromium-based — no extra code needed, just a separate store listing.
