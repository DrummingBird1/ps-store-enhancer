## 🚀 התקנה

### לפיתוח / בדיקה

1. Clone לreop הזה
2. פתח את `chrome://extensions`
3. הפעל **Developer mode** (פינה ימנית עליונה)
4. לחץ **Load unpacked** → בחר את תיקיית `extension/`
5. נווט ל-[store.playstation.com](https://store.playstation.com)

### מ-Chrome Web Store

*(קישור יתווסף לאחר הפרסום)*

## 🔗 חיבור חשבון PSN

החיבור הוא **אופציונלי**. כשמחובר:
- ספריית המשחקים מסונכרנת אוטומטית כל שעתיים
- משחקים ו-DLCs שיש לך מוסתרים מתוצאות חיפוש
- התקדמות גביעים מוצגת בעמוד המוצר

**איך לחבר:**
1. התחבר ל-[store.playstation.com](https://store.playstation.com)
2. פתח הגדרות תוסף (⚙)
3. לחץ "Auto-detect" או הזן את NPSSO Token ידנית
4. [איך להשיג NPSSO Token →](https://ca.account.sony.com/api/v1/ssocookie)

## 🛠 פיתוח

```bash
# התקנת תלויות
pnpm install

# בדיקות יחידה (Jest) — התאמת שמות, helpers, service worker מול נתוני API אמיתיים, i18n
pnpm test

# Lint + בדיקת טיפוסים (JSDoc) + בדיקת CSP של MV3
pnpm run lint && pnpm run typecheck && pnpm run check:csp

# בדיקה חיה ש-CheapShark / Frankfurter עדיין עונים כמצופה
pnpm run check:apis

# בניית dist/ (Chrome); ‎`pnpm run build:firefox` ניסיוני ולא נבדק
python scripts/build.py

# לראות את הממשק בלי להתקין: דפים אמיתיים + chrome.* מדומה בכל לשונית
python tests/harness/server.py
```

ראה [.github/TESTING.md](.github/TESTING.md) לתוכנית הבדיקות (אוטומטית + ידנית) לפני שחרור.
