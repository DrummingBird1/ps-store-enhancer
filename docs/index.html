PS Store Enhancer

Smart shopping for the PlayStation™ Store. Price history, cross-platform comparison, review scores, trophy info, wishlist alerts, and 10 languages — all in your browser.

Formerly known as GameDeals+, then PS Store Insight — same extension, same developer, better name.

Everything the PS Store should already do

All core features work without sign-in. PSN integration is opt-in.

📊
Review scores at a glance
OpenCritic / Metacritic badge injected right next to every game title. Color-coded green/yellow/red.
📉
Price history sparkline
12-month price chart embedded on the product page, with lowest-ever price highlighted.
🔀
Cross-platform comparison
See the same game's prices on Steam, Epic, GOG, Humble and more — converted to your currency.
🏆
Trophy info
Platinum availability, difficulty (1-10), estimated hours, required playthroughs for 75+ popular titles.
⭐
Wishlist alerts
Track games, set a target price, get a desktop notification when the cross-platform cheapest drops below it.
💱
18 currencies
EUR, GBP, ILS, JPY, BRL, KRW, INR, and more — daily rates from the European Central Bank.
🧹
Smart filters
Hide add-ons, currency packs, DLC, and games you already own — works with infinite scroll.
🎨
Light & Dark themes
Auto-match your system, or pick manually. Theme applies to popup, options, and injected cards.
🔒
Privacy first
No analytics. No tracking. No remote code. All your data lives in browser storage on your device.

Chrome Web Store listing coming soon. Developer install in the meantime:

⚡
Developer install
1. Download the latest release zip
2. Unzip it
3. Open chrome://extensions
4. Toggle Developer mode on
5. Click Load unpacked, select the unzipped folder
6. Visit store.playstation.com
