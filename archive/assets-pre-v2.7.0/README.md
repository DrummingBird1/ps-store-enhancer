# assets-pre-v2.7.0

The store screenshots, promo tiles and website images used up to v2.6.0, kept for reference.
They show features that no longer exist as pictured: an "estimated history" sparkline, an
OpenCritic score badge and "10 languages". v2.7.0 replaced them with images that match the real UI
(`python scripts/generate-assets/gen_screenshots.py` and friends).

Layout mirrors `assets/` (screenshots/<lang>/, promo/, docs/assets/).
