EXTENSION NAME:
PS Store Enhancer

Lowest-ever prices, cross-platform comparison, review scores, trophies & smart filters for the PlayStation™ Store.

Shopping

──────────────────────────────────────
DETAILED DESCRIPTION:
──────────────────────────────────────

PS Store Enhancer (formerly GameDeals+) enhances your PlayStation™ Store browsing experience with powerful tools to help you make smarter purchasing decisions. All core features work out of the box — no sign-in required.

🔍 PRICE INTELLIGENCE
• Real lowest-ever PC price (with its date), today's cheapest, and a "near the all-time low" flag — real data only, no estimated charts
• A price trend drawn from prices your own browser recorded
• Direct links to PSPrices for the full historical chart
• Cross-platform comparison table for the exact game (never a DLC, map or sequel) — Steam, Epic Games Store, GOG, Humble Store, and more (powered by CheapShark, converted to your currency)
• Hints about when the big sales usually start
• Edition transparency — prices from a different bundle/edition (Deluxe, Ultimate, GOTY, etc.) than the page you're viewing are clearly flagged, never blended in silently
• Live search suggestions — as you type in the store's search box, see an enriched dropdown with box art and the cheapest PC price

📊 REVIEW SCORES
• Metacritic (PC) and Steam user-rating badges next to the game title (via CheapShark)
• Color-coded: green, yellow, red — shown only when a real score exists
• Click to view the full reviews

🏆 COMPLETIONIST INFO
• Platinum trophy availability
• Difficulty rating (1-10 scale)
• Estimated completion time
• Required playthroughs, a one-glance completionist effort score and price per hour
• "Similar difficulty" picks from your own library
• Optional: live PSN trophy progress bar and your rarest remaining trophy (when connected)

🧹 SMART SEARCH FILTERS
• Hide add-ons, currency packs, and starter packs
• Hide DLC, expansions, and season passes
• Hide games you already own (manual list + optional PSN sync)
• "Mark as owned" button on every product page
• Filters work with infinite scroll

⭐ WISHLIST WITH PRICE ALERTS
• Add games to a wishlist with one click on the product page
• Set a price or "% off" target, add notes, sort and filter; get a desktop notification (or one weekly digest) when the cheapest PC price drops below it
• Records the PS Store price you see on each game's page
• Share the list as a read-only link — the list lives in the link, nothing is uploaded
• Daily background checks (no constant polling)
• Toolbar badge shows a live count of wishlist deals currently at/below your target
• Library & Wishlist stats dashboard: games owned, wishlist size, total wishlist value, deals ready to buy — computed entirely from data already on your device

💱 CURRENCY CONVERSION
• Cross-platform prices auto-convert from USD to your local currency
• 18 currencies supported (EUR, GBP, ILS, JPY, BRL, KRW, MXN, INR, and more)
• Daily exchange rates via Frankfurter (European Central Bank)

🎨 THEME & UX
• Light, Dark, High-contrast and Auto themes — pick what matches your system
• Collapse, reorder or hide the product-page cards; share a deal as an image
• "/" focuses the store's search box; ✓ / ★ marks in suggestions for games you own or wishlisted
• Right-click any text on PS Store: "Find on PS Store Enhancer" → instant CheapShark lookup
• Auto-detects your PS Store region from the URL on first visit
• Backup & restore your owned-games list and wishlist as JSON

🔗 OPTIONAL: PSN LIBRARY SYNC (Advanced)
• Power-user feature — disabled by default, requires your own PSN account
• If you choose to connect, your game library auto-syncs every 2 hours
• Owned games hidden from search results automatically
• Requires manually copying the NPSSO token from your Sony account page (full instructions inside the extension)
• You can use 100% of the extension without ever connecting — PSN integration is opt-in only
• Disconnect anytime; your manual entries are preserved

⚡ PERFORMANCE
• Smart caching reduces API calls (4-24 hour TTL per data type)
• Skeleton loading animations while data loads
• Lightweight: no external libraries, pure vanilla JavaScript

🌍 16 LANGUAGES
English, עברית (Hebrew), العربية (Arabic), Español, Français, Deutsch, Italiano, Português (BR), Nederlands, Polski, Türkçe, Русский, 日本語, 한국어, 简体中文, 繁體中文
Built-in language selector — override browser language from settings.

PRIVACY PRACTICES JUSTIFICATIONS:
──────────────────────────────────────

alarms: Periodic PSN library sync (every 2 hours), expired cache cleanup (every 6 hours), and daily wishlist price-drop checks. No data sent externally.

cookies: Detects existing PSN session cookie (npsso) for optional PlayStation Network authentication. This is the standard authentication method used by Sony's official PlayStation App since their public OAuth flow requires the NPSSO token. Only PlayStation/Sony domain cookies are accessed.

notifications: Sends a desktop notification when a wishlisted game's cross-platform price drops below the user's target price. Notifications are local — no server, no push API.

contextMenus: Adds a right-click "Find on PS Store Enhancer" entry on store.playstation.com so users can search highlighted text on CheapShark.

storage: Saves user preferences, cached API responses, owned-games list, wishlist, locally recorded prices and a small diagnostics log on the device.

webRequest (OPTIONAL permission, requested at runtime when a user clicks Connect for PSN): Used only to observe Sony's single sign-in redirect (restricted to ca.account.sony.com) and read the authorization code, because Chrome hides that redirect from extensions. Never requested at install; nothing else uses it.

Host permissions:
- store.playstation.com — content script injection
- ca.account.sony.com, m.np.playstation.com — optional PSN authentication & library sync
- cheapshark.com — cross-platform prices, all-time low, Metacritic and Steam ratings
- api.frankfurter.dev — daily currency exchange rates for display

Remote code: This extension does not use any remotely hosted code.

Single purpose: Enhances the PlayStation Store website with real price insight, cross-platform comparison, review scores, trophy information, and search filters to help users make informed purchasing decisions.
