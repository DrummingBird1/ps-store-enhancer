PS Store Enhancer（原名 GameDeals+）为 PlayStation™ Store 增加真实的价格信息、评分和智能筛选，让您用事实来决定买什么。所有核心功能开箱即用——无需登录，无需账号。

🔍 价格洞察
• PC 真实的历史最低价（含日期）、今日最低价，以及“接近历史最低”标记——只用真实数据，没有估算图表
• 根据您自己的浏览器记录的价格绘制的价格走势
• 针对确切游戏的跨平台比价（绝不会混入 DLC、地图或续作）：Steam、Epic Games Store、GOG、Humble Store 等——数据来自 CheapShark，并换算为您的货币
• 版本透明：来自其他版本或捆绑包（Deluxe、Ultimate、GOTY 等）的价格会清楚标注，绝不悄悄混在一起
• 大型促销通常何时开始的提示
• 实时搜索建议：在商店搜索框中输入时，即可看到封面和 PC 最低价
• 一键跳转 PSPrices，查看完整的 PlayStation 价格历史

📊 评分
• 游戏标题旁显示 Metacritic（PC）和 Steam 用户评价徽章（通过 CheapShark）
• 绿、黄、红三色标记——仅在存在真实评分时显示
• 点击徽章即可打开完整评测

🏆 白金攻略信息
• 75 款热门游戏的白金奖杯情况、难度（1–10）、预计时长和所需周目数——一个社区可在 GitHub 上编辑的数据库
• 一眼可见的白金攻略投入评分和每小时价格
• 来自您自己游戏库的“难度相近”推荐
• 可选，连接 PSN 后：实时奖杯进度，以及（实验性功能）您尚未获得的最稀有奖杯

🧹 智能搜索筛选
• 隐藏附加内容、货币包和入门包
• 隐藏 DLC、扩展包和季票
• 隐藏您已拥有的游戏（手动列表 + 可选的 PSN 同步）
• 每个商品页都有“标记为已拥有”按钮
• 在搜索建议中，为您已拥有或已加入愿望单的游戏显示 ✓ / ★ 标记
• 支持无限滚动；按“/”键即可跳到商店搜索框

⭐ 带价格提醒的愿望单
• 在商品页一键添加游戏
• 设置目标价格或“% 折扣”，添加备注，排序和筛选
• 当 PC 最低价达到目标时，收到桌面通知（或每周一次的汇总）
• 记录您在每个游戏页面上看到的 PS Store 价格
• 以只读链接分享列表：列表就在链接里，不会上传任何内容
• 每天在后台检查一次，不会持续轮询
• 工具栏徽章显示已达到或低于目标价的愿望单优惠数量
• 游戏库和愿望单看板：已拥有游戏数、列表大小、总价值、可立即购买的优惠——全部由您设备上的数据计算得出

💱 货币换算
• 跨平台价格自动从美元换算为您的本地货币
• 支持 18 种货币（EUR、GBP、ILS、JPY、BRL、KRW、MXN、INR 等），按商店地区设置
• 每日汇率来自 Frankfurter（欧洲央行数据）

🎨 主题与更多功能
• 主题：浅色、深色、高对比度和自动
• 折叠、重新排序或隐藏商品页卡片；将优惠分享为图片
• 在 PS Store 上右键点击任意文字，选择“在 PS Store Enhancer 比价中查找”，即可在 CheapShark 即时搜索
• 首次访问时根据网址自动识别 PS Store 地区
• 以 JSON 备份和恢复您的已拥有游戏列表和愿望单

♿ 无障碍
• 遵循系统的“减少动态效果”设置
• 卡片加载时为屏幕阅读器提供播报
• 处处可见的键盘焦点，另有高对比度主题

🔗 可选：PSN 游戏库同步（高级）
• 默认关闭——需要您自己的 PSN 账号，其余功能无需它也能使用
• 点击“连接”并粘贴您的 NPSSO 令牌（扩展内有分步指南），或者在此浏览器已登录 PlayStation 时让扩展自动检测
• PSN“玩过的游戏”列表中的游戏视为已拥有：它们会从搜索结果中隐藏，并每 2 小时重新同步一次
• 仅在您点击“连接”时，Chrome 才可能请求一项可选权限——它只用于读取登录过程中 Sony 的重定向
• 您自己的 Sony Cookie 会在之后恢复，令牌只保存在您的设备上
• 随时可以断开连接；您手动添加的条目会保留

⚡ 性能
• 智能缓存将 API 调用降到最少
• 数据加载时显示骨架屏动画
• 轻量：无外部库，纯 JavaScript
