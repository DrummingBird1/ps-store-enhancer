PS Store Enhancer (ранее GameDeals+) добавляет в PlayStation™ Store реальные данные о ценах, оценки и умные фильтры, чтобы вы выбирали покупки на основе фактов. Все основные функции работают сразу: без входа и без аккаунта.

🔍 АНАЛИТИКА ЦЕН
• Настоящий исторический минимум цены на ПК (с датой), самая низкая цена сегодня и пометка «близко к историческому минимуму» — только реальные данные, никаких оценочных графиков
• Динамика цен по значениям, которые записал ваш собственный браузер
• Сравнение цен на разных платформах для именно этой игры (никогда не DLC, не карта и не сиквел): Steam, Epic Games Store, GOG, Humble Store и другие — данные CheapShark, пересчитанные в вашу валюту
• Прозрачность изданий: цена другого издания или набора (Deluxe, Ultimate, GOTY…) помечается явно и никогда не смешивается незаметно
• Подсказки о том, когда обычно начинаются крупные распродажи
• Живые подсказки при поиске: пока вы вводите текст в строке поиска магазина, видны обложка и самая низкая цена на ПК
• Ссылка в один клик на PSPrices с полной историей цен PlayStation

📊 ОЦЕНКИ
• Значки Metacritic (ПК) и оценки пользователей Steam рядом с названием игры (через CheapShark)
• Цветовая маркировка: зелёный, жёлтый или красный — показывается, только если есть настоящая оценка
• Нажмите на значок, чтобы открыть все отзывы

🏆 ИНФОРМАЦИЯ ДЛЯ КОМПЛИТИСТОВ
• Наличие платины, сложность (1–10), примерное время и нужное число прохождений для 75 популярных игр — база данных, которую сообщество может редактировать на GitHub
• Оценка трудозатрат комплитиста с первого взгляда и цена за час игры
• Подборки игр «похожей сложности» из вашей собственной библиотеки
• По желанию, при подключённом PSN: ваш прогресс по трофеям в реальном времени и — экспериментально — самый редкий трофей, который вам ещё не достался

🧹 УМНЫЕ ФИЛЬТРЫ ПОИСКА
• Скрывайте дополнения, наборы внутриигровой валюты и стартовые наборы
• Скрывайте DLC, расширения и сезонные пропуска
• Скрывайте игры, которые у вас уже есть (ваш ручной список + необязательная синхронизация с PSN)
• Кнопка «Отметить как купленную» на каждой странице товара
• Отметки ✓ / ★ в подсказках поиска для игр, которые у вас есть или которые в списке желаний
• Работает с бесконечной прокруткой; нажмите «/», чтобы перейти к строке поиска магазина

⭐ СПИСОК ЖЕЛАНИЙ С УВЕДОМЛЕНИЯМИ О ЦЕНАХ
• Добавляйте игру одним кликом на странице товара
• Задайте целевую цену или «% скидки», добавляйте заметки, сортируйте и фильтруйте
• Получайте уведомление на рабочем столе — или один еженедельный дайджест, — когда самая низкая цена на ПК достигнет вашей цели
• Запоминает цену PS Store, которую вы видите на странице каждой игры
• Делитесь списком в виде ссылки только для чтения: список хранится в самой ссылке, ничего не загружается на сервер
• Ежедневные проверки в фоне, без постоянных запросов
• Значок на панели инструментов показывает число предложений из списка желаний, достигших цели или ниже неё
• Панель библиотеки и списка желаний: игры в коллекции, размер списка, общая стоимость и предложения, готовые к покупке — всё считается по данным на вашем устройстве

• Щёлкните правой кнопкой мыши по любому тексту в PS Store и выберите «Найти на PS Store Enhancer сравнение цен» для мгновенного поиска в CheapShark
• Определяет регион PS Store по URL при первом посещении

🔗 ПО ЖЕЛАНИЮ: СИНХРОНИЗАЦИЯ БИБЛИОТЕКИ PSN (для опытных)
• По умолчанию выключена — нужен ваш собственный аккаунт PSN, а всё остальное работает и без него
• Нажмите «Подключить» и вставьте токен NPSSO (пошаговая инструкция внутри расширения) или позвольте расширению найти его, если вы вошли в PlayStation в этом браузере
• Игры из вашего списка «сыгранные игры» в PSN считаются имеющимися: они скрываются из результатов поиска и синхронизируются заново каждые 2 часа
• Chrome может запросить одно необязательное разрешение — только когда вы нажимаете «Подключить»; оно нужно исключительно для чтения перенаправления Sony при входе
• Ваш собственный файл cookie Sony после этого восстанавливается, а токен остаётся на вашем устройстве
• Отключиться можно в любой момент; добавленные вручную записи сохраняются
