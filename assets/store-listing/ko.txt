PS Store Enhancer(구 GameDeals+)는 PlayStation™ Store에 실제 가격 정보, 리뷰 점수, 스마트 필터를 더해 줍니다. 사실에 근거해 무엇을 살지 결정하세요. 핵심 기능은 설치 즉시 작동하며 로그인도 계정도 필요 없습니다.

🔍 가격 인텔리전스
• PC 역대 최저가(날짜 포함), 오늘의 최저가, "역대 최저가에 근접" 표시 — 실제 데이터만 사용하며 추정 그래프는 없습니다
• 내 브라우저가 직접 기록한 가격으로 그리는 가격 추이
• 정확히 해당 게임만 비교하는 크로스 플랫폼 가격 비교(DLC, 맵, 후속작은 제외): Steam, Epic Games Store, GOG, Humble Store 등 — CheapShark 데이터를 사용하고 내 통화로 환산
• 에디션 투명성: 다른 에디션이나 번들(Deluxe, Ultimate, GOTY 등)의 가격은 분명하게 표시하며 조용히 섞지 않습니다
• 대형 세일이 보통 언제 시작되는지 알려 주는 힌트
• 실시간 검색 추천: 스토어 검색창에 입력하면 패키지 이미지와 PC 최저가를 보여 줍니다
• 한 번의 클릭으로 PSPrices에서 PlayStation 전체 가격 기록 확인

📊 리뷰 점수
• 게임 제목 옆에 Metacritic(PC)과 Steam 사용자 평가 배지 표시(CheapShark 제공)
• 초록, 노랑, 빨강으로 색 구분 — 실제 점수가 있을 때만 표시
• 배지를 클릭하면 전체 리뷰가 열립니다

🏆 컴플리티스트 정보
• 인기 게임 75종의 플래티넘 여부, 난이도(1–10), 예상 소요 시간, 필요한 회차 — GitHub에서 커뮤니티가 편집할 수 있는 데이터베이스
• 한눈에 보는 컴플리티스트 노력 점수와 시간당 가격
• 내 라이브러리에서 고른 "난이도가 비슷한" 게임 추천
• 선택 사항, PSN 연결 시: 실시간 트로피 진행률과, 실험적으로 아직 못 얻은 가장 희귀한 트로피

🧹 스마트 검색 필터
• 부가 콘텐츠, 화폐 팩, 스타터 팩 숨기기
• DLC, 확장팩, 시즌 패스 숨기기
• 이미 소유한 게임 숨기기(수동 목록 + 선택적 PSN 동기화)
• 모든 상품 페이지에 "소유로 표시" 버튼
• 검색 추천에서 소유 중이거나 위시리스트에 있는 게임에 ✓ / ★ 표시
• 무한 스크롤에서도 작동하며, "/" 키로 스토어 검색창으로 바로 이동

⭐ 가격 알림이 있는 위시리스트
• 상품 페이지에서 클릭 한 번으로 게임 추가
• 목표 가격 또는 "% 할인" 설정, 메모 추가, 정렬 및 필터
• PC 최저가가 목표에 도달하면 데스크톱 알림(또는 주간 요약 한 번)
• 각 게임 페이지에서 본 PS Store 가격을 기록
• 목록을 읽기 전용 링크로 공유: 목록이 링크 안에 들어 있으며 아무것도 업로드되지 않습니다
• 하루 한 번 백그라운드 확인, 상시 조회 없음
• 도구 모음 배지에 목표가 이하에 도달한 위시리스트 할인 수 표시
• 라이브러리 및 위시리스트 대시보드: 소유 게임 수, 목록 크기, 총 가치, 구매 준비된 할인 — 모두 내 기기의 데이터로 계산

💱 통화 환산
• 크로스 플랫폼 가격을 USD에서 내 현지 통화로 자동 환산
• 18개 통화 지원(EUR, GBP, ILS, JPY, BRL, KRW, MXN, INR 등), 스토어 지역에 맞춰 설정
• Frankfurter(유럽중앙은행 데이터)의 일일 환율

🎨 테마와 부가 기능
• 테마: 라이트, 다크, 고대비, 자동
• 상품 페이지 카드를 접거나 순서를 바꾸거나 숨길 수 있고, 할인 정보를 이미지로 공유
• PS Store의 아무 텍스트나 우클릭하고 "PS Store Enhancer에서 가격 비교 찾기"를 선택하면 CheapShark에서 즉시 검색
• 처음 방문할 때 URL에서 PS Store 지역을 자동 감지
• 소유 게임 목록과 위시리스트를 JSON으로 백업 및 복원

♿ 접근성
• 시스템의 "동작 줄이기" 설정을 존중
• 카드가 로드될 때 화면 낙독기용 안내
• 어디서나 보이는 키보드 포커스와 고대비 테마

🔗 선택 사항: PSN 라이브러리 동기화(고급)
• 기본적으로 꺼져 있음 — 본인의 PSN 계정이 필요하며, 나머지 기능은 동기화 없이도 모두 작동합니다
• "연결"을 클릭하고 NPSSO 토큰을 붙여 넣거나(확장 프로그램 안에 단계별 안내 있음), 이 브라우저에서 PlayStation에 로그인되어 있다면 자동으로 감지하게 하세요
• PSN "플레이한 게임" 목록의 게임은 소유한 것으로 간주되어 검색 결과에서 숨겼지고 2시간마다 다시 동기화됩니다
• "연결"을 클릭할 때만 Chrome이 선택 권한 한 가지를 요청할 수 있으며, 이 권한은 로그인 중 Sony의 리디렉션을 읽는 용도로만 사용합니다
• 내 Sony 쿠키는 작업 후 원래대로 복원되고 토큰은 내 기기에만 남습니다
• 언제든 연결을 해제할 수 있으며, 수동으로 추가한 항목은 유지됩니다
