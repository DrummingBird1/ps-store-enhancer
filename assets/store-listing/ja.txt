PS Store Enhancer（旧 GameDeals+）は、PlayStation™ Store に実データの価格情報、レビュー評価、スマートな絞り込みフィルターを追加します。事実にもとづいて買うゲームを決められます。主な機能はインストールするだけで使え、ログインもアカウントも不要です。

🔍 価格インテリジェンス
• PCでの本当の過去最安値（日付つき）、今日の最安値、「過去最安値に近い」マーク — 表示するのは実データのみで、推定グラフはありません
• あなた自身のブラウザが記録した価格から描く価格推移
• 正確なゲームを対象にしたクロスプラットフォーム価格比較（DLC・マップ・続編は含みません）：Steam、Epic Games Store、GOG、Humble Store など。CheapShark のデータを使い、お使いの通貨に換算します
• エディションの透明性：別のエディションやバンドル（Deluxe、Ultimate、GOTY など）の価格は明確に表示し、黙って混ぜることはありません
• 大型セールが始まりやすい時期のヒント
• リアルタイム検索候補：ストアの検索ボックスに入力すると、パッケージ画像とPC最安値が表示されます
• ワンクリックで PSPrices を開き、PlayStation の価格履歴を全期間で確認

📊 レビュー評価
• ゲームタイトルの横に Metacritic（PC）と Steam ユーザー評価のバッジを表示（CheapShark 経由）
• 緑・黄・赤で色分け — 実際のスコアがある場合のみ表示
• バッジをクリックすると全レビューを開けます

🏆 コンプリート情報
• 人気タイトル75本について、プラチナの有無、難易度（1〜10）、目安時間、必要な周回数を表示。コミュニティが GitHub で編集できるデータベースです
• ひと目でわかるコンプリート労力スコアと1時間あたりの価格
• ライブラリから選ぶ「難易度が近い」ゲームの提案
• 任意（PSN接続時）：トロフィーの進捗をリアルタイムで表示。試験的機能として、未取得で最もレアなトロフィーも表示

🧹 スマート検索フィルター
• アドオン、通貨パック、スターターパックを非表示
• DLC、拡張、シーズンパスを非表示
• 所持ゲームを非表示（手動リスト＋任意のPSN同期）
• 各商品ページに「所持済みにする」ボタン
• 検索候補で、所持中またはウィッシュリスト入りのゲームに ✓ / ★ を表示
• 無限スクロールに対応。「/」キーでストアの検索ボックスへ移動

⭐ 価格アラート付きウィッシュリスト
• 商品ページからワンクリックでゲームを追加
• 目標価格または「%オフ」を設定し、メモの追加、並べ替え、絞り込みが可能
• PC最安値が目標に達するとデスクトップ通知（または週 1 回のまとめ通知）
• 各ゲームのページで見たPS Storeの価格を記録
• リストを閲覧専用リンクで共有：リストはリンクの中に含まれ、何もアップロードされません
• バックグラウンドで1日1回チェック（常時ポーリングなし）
• ツールバーのバッジに、目標価格以下になったウィッシュリストのセール数を表示
• ライブラリ&ウィッシュリストのダッシュボード：所持ゲーム数、リストの件数、合計額、今すぐ買えるセール — すべて端末内のデータから計算

💱 通貨換算
• クロスプラットフォームの価格をUSDからお使いの通貨へ自動換算
• 18通貨に対応（EUR、GBP、ILS、JPY、BRL、KRW、MXN、INR など）。ストアの地域に合わせて設定
• Frankfurter（欧州中央銀行のデータ）による毎日の為替レート

🎨 テーマとその他の機能
• テーマ：ライト、ダーク、ハイコントラスト、自動
• 商品ページのカードを折りたたみ、並べ替え、非表示にでき、セールを画像として共有可能
• PS Store 上の任意のテキストを右クリックして「PS Store Enhancerで価格比較を検索」を選ぶと、CheapShark ですぐ検索
• 初回アクセス時にURLからPS Storeの地域を自動検出
• 所持ゲームリストとウィッシュリストをJSONでバックアップ・復元

♿ アクセシビリティ
• システムの「動きを減らす」設定に対応
• カードの読み込み時にスクリーンリーダー向けのアナウンス
• どこでも見えるキーボードフォーカス、さらにハイコントラストテーマ

🔗 任意：PSNライブラリ同期（上級者向け）
• 初期状態ではオフ — ご自身のPSNアカウントが必要です。それ以外の機能は同期なしで使えます
• 「接続」をクリックして NPSSO トークンを貼り付けます（手順は拡張機能内のガイドを参照）。このブラウザで PlayStation にログイン済みなら自動検出も可能です
• PSNの「プレイしたゲーム」リストにあるゲームは所持扱いになり、検索結果から非表示になって2時間ごとに再同期されます
• 「接続」をクリックしたときだけ、Chrome がオプションの権限を1つ求めることがあります。この権限は、ログイン時のSonyのリダイレクトを読み取るためだけに使います
• あなた自身のSonyのCookieは処理後に元の状態へ戻され、トークンは端末内にとどまります
• いつでも切断できます。手動で追加した項目は残ります

⚡ パフォーマンス
• スマートなキャッシュでAPI呼び出しを最小限に
• データの読み込み中はスケルトンアニメーションを表示
• 軽量：外部ライブラリなし、素のJavaScript

🌍 16言語対応
English, עברית, العربية, Español, Français, Deutsch, Italiano, Português (BR), Nederlands, Polski, Türkçe, Русский, 日本語, 한국어, 简体中文, 繁體中文
言語セレクターを内蔵 — 設定からブラウザの言語を上書きできます。

🔒 プライバシー最優先
• すべてのデータはお使いの端末内に保存
• 分析なし、トラッキングなし、データ共有なし
• 独自サーバーはありません。通信先は CheapShark（価格・評価）と Frankfurter（為替レート）のみで、接続した場合に限り Sony にも送信されます
• ポップアップと設定に「すべてのデータを消去」ボタン
• トークンやパスワードを一切記録しないローカル診断ログ
• GitHub で公開されたオープンソース（MIT）。プライバシーポリシー全文あり
